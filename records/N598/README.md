# N = 598 kissing configuration in R^11

* `config_exact.txt` – 598 vectors, each of squared norm exactly 4. Coordinates are
  rationals or `a:b` = a + b·√2 (a, b rational). The kissing configuration is x_i/2.
* `config_float.txt` – the same vectors in float64.
* `validation_exact.txt` – output of `validate/verify_qr2.py` (exact arithmetic in Q(√2)).
* `validation_float.txt` – float64 cross-check.

## Construction
1. Backbone (496 vectors, from the literature description of the 594–600 constructions):
   ±2e_i (i = 0..7) and all sign vectors (±1)^4 on 30 supports:
   6 unions of two of the pairs {0,1},{2,3},{4,5},{6,7}, and three layers k = 8,9,10,
   each with 8 supports T∪{k} (T a transversal triple, pairwise |T∩T'| ≤ 1).
   Blocks: `configs/layer30_blocks.txt` (generated by `scripts/layers.py`).
2. Free region: all vectors of squared norm 4 with |coordinates| in
   {0, 1/2, 1, 3/2, 2, √2/2, √2} that have inner product ≤ 2 with every backbone vector
   (`scripts/freecands.py --blocks configs/layer30_blocks.txt --out shells/L30_v1`,
   4714 candidates).
3. Maximum independent set of the conflict graph (inner product > 2) with the
   ARW iterated local search `src/misg.c`: `./misg shells/L30_v1.graph -T 30 -s 1`
   → 102 vectors (`free_indices.txt` = indices into `shells/L30_v1.json`).
