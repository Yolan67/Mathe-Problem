# N = 604 kissing configuration in R^11 (exact, coordinates in Q(√2))

* `validation_exact.txt` – `validate/verify_qr2.py` (exact arithmetic in Q(√2)): VALID,
  max inner product exactly 1/2, 22904 exact contacts.
* `config_float.txt` – float64 version (float shows 0.5+1e-16 only from rounding √2).
* `numerical_604_s32.txt` – the numerical configuration from which the structure was read.

## Structure (R^11 = R^8 ⊕ R^3, coords 0..7 | 8,9,10)
* backbone (496): ±2e_s (s<8), all (±1)^4 on 30 supports (`configs/layer30_blocks.txt`):
  6 unions of two pairs from {0,1},{2,3},{4,5},{6,7}; 3 layers k=8,9,10 of 8 supports T∪{k}.
* 96 = 16 pair vectors u=(±1,±1) on a pair × 6 frame vectors w = ±√2 f_i where
  f1=(1/√2,1/2,1/2), f2=(1/√2,-1/2,-1/2), f3=(0,1/√2,-1/√2) (orthonormal, |coords| ≤ 1/√2).
* 12 = √2(±f_a ± f_b), a<b: a cuboctahedron of radius 2 in the frame (pure R^3 part).
Generated by `scripts/build604.py`.

Within this decomposition 604 is maximal: ≤ 12 pure-R^3 points (kissing number of R^3)
and ≤ 6 frame vectors per pair vector u (pairwise non-positive inner products in R^3).
